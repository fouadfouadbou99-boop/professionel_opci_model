# OPCI Streamlit

Modèle professionnel d'évaluation d'actifs immobiliers OPCI.

## Fonctionnalités

- Hypothèses dynamiques
- Cash Flow sur 20 ans
- NOI
- FFO
- AFFO
- VAN
- TRI
- MOIC
- Sensibilité
- Dashboard exécutif

## Installation

pip install -r requirements.txt

## Exécution

streamlit run app.py
